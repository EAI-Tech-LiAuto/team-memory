✍️ 我想编辑调研记录（贡献者 - 推荐方式）

在线编辑，超级简单！

1

配置 GitHub Token（仅首次）

第一次编辑时，需要配置访问权限：

  • 访问：https://github.com/settings/tokens
  • 点击"Generate new token (classic)"
  • 勾选"repo"权限
  • 复制生成的 token
  • 在编辑页面粘贴保存
Token 会保存在你的浏览器中，以后不用再输入！
2

编辑调研记录

在首页找到想要编辑的调研记录：

  • 点击调研记录卡片
  • 点击"编辑此文档"按钮
  • 修改内容（所有字段都可以编辑）
  • 点击"🚀 保存到 GitHub"
保存成功后，1-2分钟网页会自动更新，团队就能看到你的修改了！
适用场景：
  • 更新企业调研信息
  • 添加走访记录
  • 补充联系人信息
  • 更新后续计划

💻 本地使用（备用方式）

如果你熟悉Git，可以选择本地方式。

常见问题

❓ Token 安全吗？
Token 保存在你的浏览器中，不会上传到服务器。但请注意：
  • 不要分享你的 token
  • 定期更新 token（建议3个月一次）
  • 如果 token 泄露，立即在 GitHub 删除
❓ 保存失败怎么办？
可能的原因：
  • Token 无效或过期 → 重新生成并配置
  • 网络连接问题 → 检查网络并重试
  • 浏览器缓存问题 → 清除缓存或使用隐私模式
❓ 多个人同时编辑会冲突吗？
GitHub 会自动处理大部分冲突。建议：
  • 不同人编辑不同的文件
  • 编辑前先看看有没有人在编辑
  • 如果出现冲突，系统会提示
❓ 网页多久更新一次？
当有人保存内容后，GitHub Pages 会自动重新部署，通常1-3分钟就能看到更新。
如果没看到，试试强制刷新浏览器（Cmd+Shift+R 或 Ctrl+Shift+R）。
❓ 我不小心改错了怎么办？
没关系！Git 有完整的历史记录，可以随时恢复到之前的版本。
联系技术同事帮忙恢复，或者重新编辑一次覆盖即可。
