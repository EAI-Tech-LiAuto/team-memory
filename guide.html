✍️ 我想贡献内容（贡献者）

需要简单的3个步骤：

1

克隆仓库到电脑

打开命令行工具，运行：

git clone https://github.com/EAI-Tech-LiAuto/team-memory.git
cd team-memory
什么是克隆？就是把这个知识库下载到你的电脑上。
2

记录你的对话

当你与Claude Code有了重要对话后：

# Windows用户
scripts\capture.bat 我的话题名称

# Mac/Linux用户
./scripts/capture.sh 我的话题名称

脚本会自动创建文件并打开编辑器，填写内容即可。

记录什么？
  • 技术决策（为什么选Orin而不选其他芯片）
  • 问题解决方案（机械臂抓取精度不够怎么解决）
  • 设计思路（人机交互安全策略怎么设计）
  • 技术调研（对比了哪些激光雷达方案）
  • 场景分析（老人照护场景有哪些需求）
3

提交到团队库

编辑完成后，运行3条命令：

git add .
git commit -m "feat: 添加XX讨论 by @你的名字"
git push
提交成功后，1-2分钟网页会自动更新，团队就能看到你的内容了！

常见问题

❓ 我不会Git怎么办？
只需要学会4条命令：
  • git clone [网址] - 下载仓库（只用一次）
  • git pull - 获取最新内容
  • git add . && git commit -m "说明" && git push - 提交内容
照着上面的步骤操作就行，5分钟就能学会！
❓ 需要记录所有对话吗？
不需要！只记录有价值、可复用的对话。
比如：重要的技术决策、复杂问题的解决方案、系统设计等。
简单的语法查询就不用记录了。
❓ 我改错了怎么办？
没关系！Git有完整的历史记录，可以随时回退。
或者提交一个修正版本，说明"更正XX内容"即可。
❓ 多个人同时提交会冲突吗？
通常不会，因为每个人记录的是不同的文件。
如果真的冲突了，Git会提示你，手动解决一下就行。
❓ 网页多久更新一次？
当有人git push后，GitHub会自动重新部署，通常1-2分钟就能看到更新。
如果没看到，试试刷新浏览器（Ctrl+F5）。
