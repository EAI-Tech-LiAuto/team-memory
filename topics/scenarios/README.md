# 家政机器人应用场景

本目录汇总了家政机器人在不同家庭场景下的应用研究和实践经验。

## 📁 场景分类

### 高频刚需场景
- [地面清洁](./home-cleaning.md) ✅ - 扫地、拖地、吸尘
- 物品整理（待补充）- 玩具、衣物、餐具归位
- 厨房辅助（待补充）- 端盘子、递工具、清理台面
- 垃圾处理（待补充）- 收集、分类、倾倒

### 中频价值场景
- 老人照护（待补充）- 提醒吃药、跌倒检测、视频通话
- 儿童陪伴（待补充）- 讲故事、作业辅导、安全监护
- 衣物管理（待补充）- 脏衣收集、叠衣服
- 宠物照料（待补充）- 喂食、清理、陪玩

### 低频增值场景
- 窗户清洁（待补充）- 擦窗户（配合专用工具）
- 植物照料（待补充）- 浇水、修剪提醒
- 家庭安防（待补充）- 巡逻、异常警报
- 物品传递（待补充）- 楼上楼下物品传递

## 📊 场景价值评估

### MVP版本重点场景
1. **地面清洁** - 最刚需，技术最成熟
2. **简单物品归位** - 体现智能化，技术可实现
3. **基础语音交互** - 提升用户体验

### 完整版本扩展场景
4. **垃圾分类处理** - 提升便利性
5. **老人陪护监测** - 高价值，差异化
6. **多任务并行** - 提高效率
