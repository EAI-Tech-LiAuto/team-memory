# 人机交互安全技术

## 概述

家政机器人在家庭环境中与人类（包括老人、儿童）共享空间，安全是第一要务。本文档描述人机协作场景下的安全技术方案。

## 安全设计原则

### 三层防护
1. **主动避让**: 提前感知人体，规划路径避开（最优）
2. **柔顺接触**: 轻微碰触时缓冲减速（次优）
3. **紧急制动**: 异常碰撞时立即停机（兜底）

### 安全等级
- **Level 0**: 无人环境（正常速度运行）
- **Level 1**: 检测到人体3米内（降速50%）
- **Level 2**: 人体1米内（降速70%，提示音）
- **Level 3**: 人体接触（立即停止，待确认）

## 感知层安全

### 人体检测
**多传感器融合**:
- **RGB-D相机**: 识别人体骨架关键点（准确度高）
- **激光雷达**: 检测运动物体（速度快）
- **超声波**: 近距离补盲（0.3m内）
- **毫米波雷达**: 穿透遮挡物（家具后的人）

**特殊人群识别**:
```python
# 儿童检测（低于1.2m的人体）
if person_height < 1.2 and person_detected:
    safety_level = Level_3  # 最高警戒
    max_speed = 0.2  # 降至0.2m/s

# 老人检测（行动缓慢、弯腰）
if person_velocity < 0.5 and posture_bent:
    safety_distance = 2.0  # 加大安全距离至2米
```

### 危险区域识别
- **楼梯边缘**: 悬崖传感器 + 视觉确认
- **湿滑区域**: 地面反射特征（厨房、卫生间）
- **狭窄通道**: 小于机身宽度+20cm不通过
- **玻璃门**: 反射环境识别（避免撞击）

## 运动控制安全

### 动态避障
**DWA算法（Dynamic Window Approach）**:
```python
# 考虑人体运动趋势的避障
if human_moving_toward_robot:
    # 预测人体未来1秒位置
    future_pos = human_pos + human_velocity * 1.0
    # 规划避开未来位置的路径
    path = plan_avoid(future_pos, safety_margin=0.8)
```

### 速度限制
| 场景 | 最大线速度 | 最大角速度 | 加速度 |
|------|-----------|-----------|--------|
| 无人环境 | 1.0 m/s | 90°/s | 0.5 m/s² |
| 人体3m内 | 0.5 m/s | 60°/s | 0.3 m/s² |
| 人体1m内 | 0.3 m/s | 30°/s | 0.2 m/s² |
| 狭窄空间 | 0.2 m/s | 20°/s | 0.1 m/s² |

### 机械臂安全
**力矩限制**:
```python
# 关节力矩监测
if joint_torque > safe_threshold:
    # 碰到人体或障碍物
    robot_arm.stop()
    robot_arm.retract(distance=0.1)  # 后退10cm
    play_audio("不好意思，碰到您了")
```

**工作空间限制**:
- 头部高度以上（1.6m+）: 禁止运动
- 地面以下（0.1m-）: 禁止运动
- 人体半径50cm内: 速度限制0.1m/s

## 物理安全设计

### 碰撞缓冲
- **柔软外壳**: 机身覆盖5mm弹性材料（TPU）
- **圆润边角**: 所有边角R≥10mm
- **碰撞传感器**: 接触式开关分布全身（16个点）

### 紧急停止
**多重触发方式**:
1. 物理急停按钮（3个：顶部、左侧、右侧）
2. 语音急停指令"停止！"
3. 遥控器急停
4. APP远程急停
5. 异常力矩/电流（自动触发）

**急停响应时间**: <100ms

## 交互安全

### 语音提示
**运动前预警**:
```
机器人: "我要开始清扫了，请注意安全"（3秒倒计时）
机器人: "检测到您在前方，我绕个路"
机器人: "前面通道比较窄，我慢慢通过"
```

**异常提示**:
```
机器人: "对不起，路被挡住了，能帮我挪一下椅子吗？"
机器人: "我的机械臂碰到东西了，已经停下"
机器人: "检测到楼梯，为安全起见我不会靠近"
```

### 灯光警示
- **正常运行**: 蓝色呼吸灯
- **接近人体**: 黄色常亮
- **停止避让**: 红色闪烁
- **充电中**: 绿色常亮

## 场景安全策略

### 老人照护模式
```yaml
safety_config:
  max_speed: 0.3  # 永远不超过0.3m/s
  safety_distance: 2.0  # 2米安全距离
  voice_volume: +20%  # 提高音量
  fall_detection: enabled  # 跌倒检测
  emergency_call: enabled  # 一键呼叫家人
```

### 儿童在场模式
```yaml
safety_config:
  max_speed: 0.2  # 极慢速度
  child_zone_forbidden: [楼梯口, 厨房, 阳台]  # 禁区
  toy_recognition: enabled  # 识别玩具避让
  sharp_object_alert: enabled  # 尖锐物品警报
```

### 宠物在场模式
```yaml
safety_config:
  pet_detection: enabled  # 宠物识别
  avoid_pet_sleeping_area: true  # 避开宠物窝
  quiet_mode: enabled  # 降低噪音（不惊扰宠物）
```

## 数据安全与隐私

### 视觉数据处理
- **本地处理**: 人体检测算法在本地运行，不上传视频流
- **隐私保护**: 仅提取骨架关键点，不保存人脸图像
- **数据加密**: 必要数据传输使用TLS 1.3加密

### 用户同意
- 首次使用时明确告知数据收集范围
- 可选择关闭摄像头（仅用激光雷达导航）
- 数据随时可删除

## 应急预案

### 故障降级
```
传感器故障 → 停止自主运动，手动遥控模式
网络断开 → 本地模式（基础功能）
机械臂故障 → 禁用机械臂，保留清洁功能
电池故障 → 立即停机，警报提示
```

### 事故响应流程
1. 自动保存故障前30秒日志
2. 蜂鸣器响起 + 红灯闪烁
3. 推送通知到用户APP
4. 自动联系售后服务
5. 远程诊断或上门维修
