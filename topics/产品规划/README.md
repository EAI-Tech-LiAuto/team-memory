### 工作计划（对话记录）

#### 李君 - 2个月工作计划
- **文档**: [家政机器人项目研究计划](../../conversations/2026-01/home-service-robot-research.md)
- **时间周期**: 8周（2个月）
- **核心内容**: 基于两个月工作计划，针对家政机器人场景设计完整的产品方案。涵盖行业调研、技术选型、商业模式、供应链规划等核心内容
- **交付成果**: 80-100页详细商业计划书

#### 郎博 - 1个月加速计划（工业+家用双场景）
- **文档**: [1个月加速计划](../../conversations/2026-01/one-month-accelerated-plan.md)
- **时间周期**: 4周（1个月）
- **核心内容**: 时间压缩50%（8周→4周），场景扩展为工业+家用双线布局。高强度并行作战，2月底交付50-60页商业计划书
- **成本预算**: ¥280-350万
- **团队配置**: 34-39 FTE（现有团队25-30人 + 自动驾驶顾问6人 + 外部专家20-25人）
- **特点**:
  - 工业场景70%精力，家用场景30%精力
  - 高度并行作战
  - Phase 1聚焦工业版，Phase 2启动家用版

#### 朱俊蓉 - 1个月工作计划（纯家用场景）
- **文档**: [家用人形机器人1个月工作计划](../../conversations/2026-01/home-robot-one-month-plan.md)
- **时间周期**: 4周（1个月）
- **核心内容**: 100%聚焦家用场景，5-6人精简团队配置。30天完成市场验证、技术路线确认、商业计划制定
- **成本预算**: ¥100-150万
- **团队配置**: 5-6人精简配置（战略组2人、软件模型组2人、硬件组2人）
- **特点**:
  - 纯家用场景聚焦
  - 深度竞品分析（10家企业）
  - 30个深度访谈 + 500份问卷
  - 强调数据驱动决策和快速迭代

## 🎯 核心策略差异

### 李君方案（家政/家用服务）
- **优势**: 时间充足（8周），调研深度最大，聚焦家政场景
- **特点**: 详细的场景分析（地面清洁、物品整理、老人照护等）
- **适合**: 需要扎实的市场和技术验证，家政服务场景深度探索

### 郎博方案（工业+家用双场景）
- **优势**: 工业+家用双场景布局，自动驾驶技术深度复用
- **特点**: 高强度并行作战，工业场景优先（70%精力）
- **适合**: 时间紧迫但资源充足，想要双线布局

### 朱俊蓉方案（纯家用场景）
- **优势**: 成本最低，100%家用聚焦，团队精简高效
- **特点**: 深度竞品分析（10家企业），用户需求驱动
- **适合**: 资源有限，想快速验证家用市场
