用于分类和搜索

📝 如何使用：

  1. 复制内容：点击上方"📋 复制到剪贴板"按钮
  2. 创建文件：
    • 打开 Finder（访达），找到 team-memory 文件夹
    • 进入 research 文件夹
    • 根据企业类型进入对应文件夹（如 companies）
    • 创建新的 .md 文件，文件名为企业名称（如 摩尔芯光.md）
    • 提示：可以右键 → 新建文本文件，然后改扩展名为 .md
  3. 粘贴内容：用文本编辑器打开刚创建的文件，粘贴（Cmd+V）复制的内容并保存
  4. 更新索引：
    • 打开"终端"应用（在启动台或应用程序/实用工具中）
    • 输入：cd ~/Desktop/team-memory（或你存放的位置）然后按回车
    • 输入：python3 scripts/update-index.py 然后按回车
  5. 提交到 GitHub：在终端依次输入：
    • git add .
    • git commit -m "feat: 添加XXX调研记录"（XXX改为企业名）
    • git push
💡 更简单的方法：
如果觉得上述步骤复杂，可以使用 在线编辑器，无需手动创建文件和运行命令！
