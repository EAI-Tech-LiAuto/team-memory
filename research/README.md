# 行业调研

本模块用于记录团队在业务拓展过程中走访的企业、高校、专家等外部资源的信息，便于团队成员了解行业动态、学习先进经验、积累行业知识。

## 📁 目录结构

```
research/
├── README.md              # 本文件，使用说明
├── companies/             # 企业调研记录
├── universities/          # 高校/研究机构调研记录
├── experts/              # 专家/个人访谈记录
└── attachments/          # 相关附件（PPT、PDF等）
```

## 🎯 使用场景

- 记录走访企业的基本信息和联系方式
- 保存高校合作机会和技术资源
- 整理专家访谈内容和见解
- 跟踪调研进展和后续计划
- 分享行业观察和学习收获

## 📝 添加新记录

### 方法一：使用脚本（推荐）

```bash
cd ~/desktop/team-memory
./scripts/add-research.sh
```

按提示输入信息即可自动创建标准格式的调研记录。

### 方法二：手动创建

1. 在对应目录下创建 Markdown 文件
2. 使用模板填写信息（见下方）
3. 提交到 Git
