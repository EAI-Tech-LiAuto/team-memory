# 🚀 一键保存并同步功能

这个功能让您可以直接在网页上点击按钮，自动完成保存、提交到Git和推送到GitHub的所有操作。

## 📋 功能说明

在编辑调研记录页面，您会看到三个按钮：

1. **取消** - 返回上一页，不保存
2. **💾 保存并下载** - 传统方式，下载文件到本地
3. **🚀 保存并同步** - 新功能！一键完成所有操作

## 🎯 使用方法

### 第一次使用（一次性设置）

1. **启动本地服务器**
   - 打开项目文件夹（~/Desktop/team-memory）
   - 双击 `启动本地服务器.command` 文件
   - 会弹出终端窗口，显示"服务器运行中"
   - **保持这个窗口打开**（最小化即可）

2. **编辑调研记录**
   - 在网页上编辑信息
   - 点击 `🚀 保存并同步` 按钮
   - 等待几秒，会提示"成功！"
   - 刷新主页即可看到更新

### 日常使用

只要保持服务器运行，每次编辑后直接点击 `🚀 保存并同步` 即可！

## 🔧 工作原理

```
用户点击按钮
    ↓
收集表单数据
    ↓
生成Markdown文件
    ↓
发送到本地服务器（localhost:5000）
    ↓
服务器保存文件到仓库
    ↓
自动执行 Git 操作
    ↓
推送到 GitHub
    ↓
完成！
```

## ⚠️ 注意事项

1. **必须先启动服务器**
   - 如果点击按钮后提示"服务器未启动"，请先双击 `启动本地服务器.command`

2. **保持服务器运行**
   - 服务器窗口可以最小化，但不要关闭
   - 如果关闭了，需要重新双击启动

3. **只在本地使用**
   - 服务器只在您的电脑上运行（localhost）
   - 不会暴露到互联网，安全可靠

## 🆚 两种方式对比

| 功能 | 保存并下载 | 保存并同步 |
|------|-----------|-----------|
| 操作步骤 | 3步（下载→替换→运行脚本） | 1步（点击按钮） |
| 需要终端 | 是 | 否 |
| 自动提交Git | 否 | 是 |
| 自动推送GitHub | 否 | 是 |
| 需要服务器 | 否 | 是（一次启动即可） |

## 🐛 故障排除

**问题1：点击按钮后提示"服务器未启动"**
- 解决：双击 `启动本地服务器.command` 启动服务器

**问题2：服务器启动失败**
- 解决：确保已安装Python3和Flask
  ```bash
  pip3 install flask flask-cors
  ```

**问题3：提示"同步失败"**
- 检查是否有Git权限
- 检查网络连接
- 查看服务器终端窗口的错误信息

## 💡 建议

- 开机后启动服务器，全天保持运行（资源占用很小）
- 或者设置开机自动启动（进阶用户）
- 如果长时间不使用，可以关闭服务器窗口
