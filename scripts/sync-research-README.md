# 自动同步调研记录

这个脚本可以自动将下载的调研记录文件同步到仓库并提交到 Git。

## 使用方法

### 方法1：双击快捷方式（最简单）

1. 在编辑页面点击"保存并下载"
2. 双击项目根目录下的 `同步调研记录.command` 文件
3. 脚本会自动完成所有操作

### 方法2：运行脚本

```bash
cd ~/Desktop/team-memory/scripts
./sync-research.sh
```

## 工作原理

脚本会：
1. 🔍 在Downloads文件夹中查找最新的.md文件
2. 📁 根据文件名自动判断类型（企业/高校/专家）
3. 📄 复制文件到对应的research目录
4. 📤 自动提交到Git
5. 🚀 推送到GitHub
6. ✨ 完成！刷新网页即可看到更新

## 注意事项

- 确保下载的文件在 ~/Downloads 文件夹中
- 脚本会自动找最新的.md文件
- 如果有多个新文件，会选择最新的那个

## 故障排除

如果脚本运行失败：
1. 检查文件是否在 Downloads 文件夹
2. 确保文件是 .md 格式
3. 检查是否有 Git 权限
