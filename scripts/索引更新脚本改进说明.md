# 索引更新脚本改进说明

## 🎯 改进内容

### 1. 自动创建企业调研部分
**之前的问题**：
- 如果 index.html 中没有企业调研部分，脚本不会创建
- 导致新添加的调研记录无法显示

**现在的行为**：
- ✅ 如果存在调研部分 → 自动更新内容
- ✅ 如果不存在但有调研数据 → 自动创建完整的 HTML 部分
- ✅ 如果没有调研数据 → 跳过（不创建空部分）

### 2. 优化卡片样式
**改进项**：
- 统一卡片 HTML 格式，匹配主页样式
- 优化状态显示：
  - ✅ 已接洽 (status-contacted)
  - 🔵 初步接触 (status-initial)
  - ⏳ 待跟进 (status-pending)
  - 🤝 已合作 (status-partner)
- 改进布局结构：
  - card-header: 标题 + 日期
  - card-meta: 地点 + 类型
  - card-tags: 技术标签
  - card-footer: 状态徽章

### 3. 支持多种标题格式
- 兼容 `🔍 行业调研`
- 兼容 `🏢 企业调研`
- 正则匹配自动识别

---

## 🔧 使用方法

### 手动运行
```bash
cd ~/Desktop/team-memory
python3 scripts/update-index.py
```

### 自动运行（通过 GitHub Actions）
1. 按照 `自动索引更新设置指南.md` 设置 GitHub Action
2. 每次添加/修改调研记录时自动运行
3. 无需手动操作
